# Paper digest — 2608.03609 Stateful Tool-Enabled Agentic Deployment / First-Order Computation Tree Logic

## 1. Abstract (compressed) `[Evidenced — Atom summary]`

Agentic systems (single large language model + tool orchestration harness over
persistent relational operational data) need pre-deployment guarantees against
business requirements on workflow execution and data evolution. The authors
formalise such systems as Stateful Tool-Enabled Agentic Deployments, give
semantics, define verification against First-Order Computation Tree Logic
specifications, and prove the problem undecidable. Under finite-domain
restriction plus local symmetry (tool-interface equivariance, tool-uniform
semantics, agent equivariance), First-Order Computation Tree Logic is preserved
exactly and verification is PSPACE-complete. Large language model agents can
violate equivariance; a canonical deployment wrapper enforces it for arbitrary
base agents while preserving already-equivariant behaviour. Computing the
required canonical representations is graph-isomorphism-hard. Illustration:
case-management workflow with a wrapped agent.

## 4. Methodical understanding (formal-systems checklist)
