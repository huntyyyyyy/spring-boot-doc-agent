# Paper digest — 2607.20531 DynamicMCPBench

## 1. Abstract (compressed) `[Evidenced — Atom summary]`

Benchmarks that grade final answers or fixed tool lists break on live,
stateful Model Context Protocol servers. DynamicMCPBench is a reusable
framework: explore live tools, distill successful traces into path-agnostic
effect checkpoints (equivalence sets, minefields, partial order), score
candidates by whether they reproduce those effects under deterministic
replay — never by answer matching. Study scale: 24 models, 121 servers,
750 balanced tasks, pass³.

## 2. Type justification `[Inferred]`

Primary **benchmark** (TaskSpec corpus + scoring protocol as contribution).
Secondary **systems-artifact** (pipeline / `dmcp` package) and **empirical**
(leaderboard + human validation κ≈0.76). Not theoretical; not a systematic
review.

1. **Plant:** live Model Context Protocol servers + deterministic replay worlds.  
2. **Measure:** Tier-1 effect checkpoints; pass³; headline excludes Tier-2 large-language-model judge.  
3. **False-green risk:** adopting their leaderboard as our Verification and Validation Accept; ignoring minefields / `llm_witness`.  
4. **Public artifact:** Hugging Face `anonsubmitter/DynamicMCPBench` (dataset, 2026-06-17); anonymous.4open code link **403** from this environment — **exact engine = 0 / pending** for production Adopt.  
5. **Novelty vs packaging:** effect-checkpoint / equivalence / minefield / partial-order scoring is the algorithm class; packaging is review-anonymized.
