# Paper digest — 2608.04278 (worked example of the framework)

## 1. Abstract (compressed) `[Evidenced — Atom summary]`

Coding agents keep prose conclusions across sessions without the program state
that supported them. After upstream change, builds can still pass while prior
verification claims are invalid. The paper presents artifact-anchored claim
memory: sub-path artifacts, digest anchors, evidence strength separate from
freshness, and withdrawal to `unprovable` when replacement content is missing.
Evaluation uses generated repositories with known ground truth (42 sessions).
Bounded claim: helped the smaller model’s provability judgments; no efficiency
or repair-quality claim.

## 2. Type justification `[Inferred]`

Primary **empirical**: controlled conditions, paired measures, Wilcoxon tests,
threats-to-validity section. Secondary **systems-artifact** (defines a memory
machine) and **analytic** (META / ANCH / DISP vocabulary). Not a systematic
review; not a complexity-theoretic paper.
