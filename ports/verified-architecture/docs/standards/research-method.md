# Research method standards

## Claim tiers

| Tier | Meaning |
| --- | --- |
| **Evidenced** | Primary docs / papers / DeepWiki Ask with URL |
| **Confirmed** | Demonstrated in *this* repo or named plant |
| **Unknown** | Open — Spike required |

## Bloom before Implement

Remember → Understand → Apply → Analyze → Evaluate → **Create** (tickets with
Accept). Chat memory is not evidence.

## Sources

Prefer primary `llms.txt`, vendor specs, DeepWiki Ask, and peer-reviewed papers.
Star counts are cartography, not proof.
