# Research method standards

## Claim tiers

| Tier | Bound | Fail-mode |
| --- | --- | --- |
| **Evidenced** | Primary docs / papers / DeepWiki Ask with URL | Citing a star count as Evidenced |
| **Confirmed** | Demonstrated in *this* repo or named plant | Claiming Confirmed from chat memory |
| **Unknown** | Open — Spike required | Labeling Unknown as research-complete |

## Bloom before Implement

Remember → Understand → Apply → Analyze → Evaluate → **Create** (tickets with
Accept). Chat memory is not evidence; Implement without Accept fails Definition
of Ready.

## Sources

Prefer primary `llms.txt`, vendor specs, DeepWiki Ask, and peer-reviewed
papers. Star counts are cartography, not proof.
